## NLP 시간 핵심   
- LLM이 가진 모든 단어의 묶음을 Corpus(말뭉치)라 하고 거기서 필요한 단어들만 끄집어 내서 구성한 것을 Vocabulary(어휘사전)이라 함 
- 벡터라이징과 임베딩: AI가 처리할 수 있게 텍스트를 연속된 숫자로 바꾸는게 벡터라이징. 이때 의미있는 숫자로 바꾸는게 임베딩
- 임베딩을 위해 단어의 빈도를 이용하는 대표적 방법이 TF-IDF이며 RAG의 BM25(Best Matching 25)로 발전함

## 딥러닝 개요

  - 어떤 단어의 의미는 그 주변 단어를 기반으로 분석할 수 있다.
  - 주변 단어가 비슷한 단어들은 유사한 의미일것이다.  
- 역전파란? 딥러닝은 정답과의 오차를 많은 반복을 통해 줄여 나가는 학습법. 이 오차를 줄이는 과정을 역전파라 함.
- 임베딩과 차원 의미: 
  - 차원은 한 단어의 의미를 바라보는 관점. 이 차원은 인간이 정하는게 아니고 임베딩 모델이 정함

## LM(언어모델)
- RNN은 역전파 과정에서 기울기가 점점 작아져 학습 안되는 vanishing gradient 현상 발생 
- LSTM과 GRU: 
  - 목적: 역전파 단계가 많아져도 메모리가 소실되지 않게 하자
  - 과거 정보와 새로운 정보를 적절히 섞어 메모리를 업데이트
- Attention
  - 답변 후보의 확률을 계산할 때 질문의 단어 중 관련 높은 단어에 주목해 보자 
    -> 인간도 질문에 답변할 때 질문 중 중요한 단어를 생각하면서 가장 최상 답변한다.
  - 동음이의어/다의어를 구분 못하는 워드임베딩의 한계를 Contextual 임베딩(단어간의 관계 이용)으로 극복
  
## 트렌스포머 기본 개념
- 단어가 유사하다는 건 거리가 가깝다는 의미 -> 1 - 유사도 = 거리
- 내적(Dot Product): 
  - 두 벡터의 유사도를 코사인 유사도로 계산한 결과
  - 유사도를 각 벡터가 바라보는 방향간의 각도로 계산: 
  - 내적: 1(cos 0도)이면 완전 동일, 0(cos 90도)이면 전혀 안 닮음
  - 벡터의 길이를 동일한 크기로 맞춰 비교할 수 있어서 코사인 유사도를 씀
* WHY 내적이 중요?
- 학습: 다음 토큰을 맞히도록 가중치를 조정하는 과정에서, 내적을 통해 기울기가 움직이며 관련 있는 벡터끼리 가까워짐
- 어텐션: 각 토큰의 질의(Q)와 다른 토큰의 키(K)를 내적해, 어디를 얼마나 참조할지 가중치를 배분함
- 추론: 마지막 은닉 벡터와 각 토큰 임베딩을 내적해, 값이 가장 큰 토큰을 답으로 선택함
   
- 선형변환(Linear transformation)
  - 입력벡터와 가중치를 행렬 연산하여 결과값을 계산하는 것
  - 가중치를 계속 조정하여 결과값을 정답에 맞게 조정하기 위해 사용    
  - 행렬연산 특징: (1,3) * (3, 2) -> 가운데 3 없어지고 (1,2)이 됨
- Softmax
  - 결과 벡터의 값을 합이 1이 되도록 0 ~ 1 사이로 고르게 분포시키는 함수 
  
## Transformer
- (중요) LSTM, GRU 한계: 병렬처리 불가(순차처리만 가능), 장기의존성(순차 처리 하다보니 앞에 기억을 잃어 버림) 문제 발생
- 트렌스포머는 병렬처리 아키텍처로 변경함으로써 장기의존성 문제를 해결
- 목적: 질문을 잘 이해(Encoder)하고 가장 좋은 답변을 내자(Decoder) 

### Encoder
  > Encoder과정이 질문을 잘 이해하는게 목적이라는 것과 그것을 한꺼번에 병렬 처리한다는 의미를 이해하세요. 
  > 여기서 질문이란 여러분이 입력한 프롬프트입니다. 그걸 임베딩한 벡터죠.
  > 여러분이 어떤 질문을 받았을 때 잘 이해하려면 어떻게 해야할까요?
  > - 질문 문장에 포함된 단어간의 관계(어떤 단어가 더 유사한지, 관계가 깊은지)를 파악해야죠 -> 이게 Self Attention
  > - 질문 문장을 한꺼번에 받아서 관계를 파악하니까 병렬처리죠.
  > Query와 Key를 내적해 "어디를 얼마나 볼지" 비율을 정하고, 그 비율로 Value를 섞습니다. 

  - 입력(질문) 벡터 * 가중치 = 결과 벡터
  - 가중치와 결과 벡터를 Query, Key, Value 3개로 나눔
    - 예) 책 찾을 때 질의어가 Query, 책 목차가 Key, 실제 책 내용이 Value 벡터임
    - Encoder에서 Q, K, V는 모두 동일합니다.  
  - 처리 과정 
    - 1.입력(질문) 토큰화 & 임베딩: 질문 문장을 단어로 쪼개고 벡터로 변환
    - 2.위치 Encoding(Positional Encoding)
      - 질문 단어의 위치를 고유하게 하는 작업
      - 단어의 순서가 문맥에 중요하기 때문에 반드시 해야 함
      - Sin/Cos 함수를 이용      
    - 3.Multi-head Attention
      - 여러 관점으로 질문을 이해하기 위한 목적: 예) 문법, 의미, 시간, 감성적 관점 
      - 각 Head 내 처리 단계
        - 질문의 단어간의 연관성을 계산: Q*K 내적 계산 
        - Q * K 결과 벡터를 제곱근으로 크기를 눌러주고 Softmax로 0~1 사이로 변환 -> Attention Score 계산
        - 결과벡터(Attention Score) * Value 벡터를 내적 연산하여 문맥이 반영된 최종 벡터(Attention Output)을 생성 
        - 결국 결과는 질문의 각 단어간의 관계가 잘 표현된 벡터를 얻을 수 있는 것임 -> 질문의 맥락을 잘 이해할 수 있게 됨 
    - 4.선형 변환
      - Multi-head Attention 결과를 합친 후 안에 가중치를 또 한 번 섞음
      - 이 가중치 섞는 과정이 선형 변환
    - 5.잔차연결 + 정규화(Add & Normalization)
      - 정규화: 벡터의 가중치를 한번 더 고르게 가공하는 것   
      - 잔차연결: 원래 입력(질문) 벡터를 선형 변환 결과 벡터에 더해줌 
        - 원래 질문의 맥락을 강화시키기 위함
        - 질문을 최종으로 이해할 때 원래 질문을 한번 더 생각하는 거임
    - 6.FFN(Feed Forward Network)
      - 맥락을 더 넓은 관점으로 이해하기 위함 
      - 차원을 2배 늘려서 수행
      - 결과는 다시 원래 차원으로 줄임
    - 7.잔차연결 + 정규화(Add & Normalization): FFN 결과에 대해 수행

### Decoder
- 개념도
  ![](images/2026-07-30-15-55-37.png) 
- 처리과정
  - 1.답변 토큰화 & 임베딩: 학습시에는 토큰화 + 임베딩, 추론시에는 토큰화는 당연히 안하고 임베딩만 수행
  - 2.위치 Encoding(Positional Encoding)
    - 답변 단어의 위치를 고유하게 하는 작업
    - 단어의 순서가 문맥에 중요하기 때문에 반드시 해야 함
    - Sin/Cos 함수를 이용      
  - 3.Multi-head Attention
    - 여러 관점으로 답변을 이해하기 위한 목적: 예) 문법, 의미, 시간, 감성적 관점 
    - 각 Head 내 처리 단계
      - Encoder의 Self-Attention과 거의 유사하나, 미래 답변은 가리는 Masked Self-Attention이라는 것이 다름 
      - 답변 단어간의 연관성을 계산: Q*K 내적 계산 
      - Q * K 결과 벡터를 제곱근으로 크기를 눌러주고 Softmax로 0~1 사이로 변환 -> Attention Score 계산
      - 결과벡터(Attention Score) * Value 벡터를 내적 연산하여 문맥이 반영된 최종 벡터(Attention Output)을 생성 
      - 결국 결과는 답변의 각 단어간의 관계가 잘 표현된 벡터를 얻을 수 있는 것임 -> 답변의 맥락을 잘 이해할 수 있게 됨 
  - 4.Cross Attention
    - 위 Self-Attention과 유사하나 Q가 답변이 되고, K/V가 질문이 된다는 것이 다름
    - 목적은 최고의 답변을 내기 위해 가장 주목해야 할 질문의 단어를 찾는 것임
  - 5.선형 변환
    - Cross Attention 결과를 합친 후 안에 가중치를 또 한 번 섞음
    - 이 가중치 섞는 과정이 선형 변환
  - 6.잔차연결 + 정규화(Add & Normalization)
    - 정규화: 벡터의 가중치를 한번 더 고르게 가공하는 것   
    - 잔차연결: 지금까지의 답변 벡터를 선형 변환 결과 벡터에 더해줌 
      - 답변 맥락을 강화시키기 위함
      - 답변을 최종으로 이해할 때 지금까지의 답변을 한번 더 생각하는 거임
  - 7.FFN(Feed Forward Network)
    - 맥락을 더 넓은 관점으로 이해하기 위함 
    - 차원을 2배 늘려서 수행
    - 결과는 다시 원래 차원으로 줄임
  - 8.잔차연결 + 정규화(Add & Normalization): FFN 결과에 대해 수행
